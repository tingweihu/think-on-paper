# 列印與紙張

[返回首頁](../../README.md) · [English](../en/print.md) · [日本語](../ja/print.md)

每款另提供 `titled.pdf`，在左上角寫上英文版型名稱，方便辨識與整理。它與無字 `blank.pdf` 使用相同的可書寫幾何；PNG 仍由無字 PDF 渲染。

下載各款的 `blank.pdf` 作為列印檔；PNG 僅供預覽。預設頁面是 A5（148 × 210 mm），使用 `a5-draft` 暫定 profile。印表機選 A5 紙並以「實際大小／100%」開始試印，不要同時套用「符合頁面」，否則行距可能變動。先印一張，量測可寫區，再決定是否需要縮放。

PDF 沒有滿版暖黃底。印在微黃道林紙上時，紙色由紙材本身提供；數位縮圖的暖黃只供觀看。頁面左側預留裝訂空間，上下各有 12 mm 安全距離。不同印表機的不可列印邊可能裁掉內容，因此首次使用時請查看實際紙樣。

每款下載另有 `a5-contrast` 深色墨線 SVG／PDF，沿用相同幾何與留白。需要較清楚的線條時可選擇深色版本，例如[四象限深色 PDF](../../templates/quadrant/exports/a5-contrast/blank.pdf)。
