# 貢獻指南

[返回首頁](../../README.md) · [English](../en/contribute.md) · [日本語](../ja/contribute.md)

提出新格式前，先查看 [`catalog-144.csv`](../../catalog-144.csv)、三語目錄與現有版型 Manifest。說明新格式在分區結構或書寫行為上的差異；只換線距、方向或紙色，應作為現有格式的變體。新增構圖函式、穩定 ID、三語用途與限制、三語步驟及同場景示例，再生成檔案並執行 QA。空白版型不可加入任何字、頁碼、日期或 Logo。

翻譯可以改善自然度，但不能刪掉限制、示例或列印提醒。請標示是否經真人審校；未審校的數位預覽不宣稱已完成審校。對列印問題，附上印表機縮放選項、紙張與量測結果；不要提供私人筆記。本專案原創程式、文件、示例與圖稿統一採 [MIT](../../LICENSE)。

提交時請列出每段程式、文字與圖稿的作者及來源，確認有權以 MIT 提供。第三方圖片、字型、商標或他人筆記不得直接加入；外部貢獻仍須來源與權利審查。
