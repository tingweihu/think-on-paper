# Printing and paper

[Home](../../README.en.md) · [繁體中文](../zh-TW/print.md) · [日本語](../ja/print.md)

Each format also offers `titled.pdf`, with its English name in the top-left corner for identification. It uses the same writing geometry as the wordless `blank.pdf`. The PNG remains a preview rendered from the wordless PDF.

Download each format's `blank.pdf` for printing. The PNG is a preview. The draft page is A5 (148 × 210 mm) using a provisional `a5-draft` profile. Select A5 paper and start with “Actual size” or 100% rather than “Fit to page”, which can alter spacing. Print one sheet, measure the writing area, and adjust only after checking the result.

The PDF does not print a full warm-yellow background. On ivory paper, the stock supplies the color; the warm digital thumbnail is only a viewing aid. The page reserves space at the left for binding and 12 mm safe margins at the top and bottom. A printer's nonprintable edge may clip marks, so inspect the first sheet before regular use.

Every format also has darker-ink SVG/PDF under `a5-contrast`, preserving geometry and margins. For stronger lines, choose that option; for example, the [darker quadrant PDF](../../templates/quadrant/exports/a5-contrast/blank.pdf).
