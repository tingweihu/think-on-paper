# 三言語の用語集

[ホーム](../../README.ja.md) · [繁體中文](../zh-TW/glossary.md) · [English](../en/glossary.md)

| 日本語 | 繁體中文 | English | このプロジェクトでの意味 |
|---|---|---|---|
| コーネル式ノート | 康乃爾式筆記頁 | Cornell notes | 手がかり、本文、要約を分ける印刷用のページです。学習効果を実証したという主張ではありません。 |
| マンダラ式の発想／九マス展開 | 曼陀羅思考／九宮展開 | mandala idea expansion | 中心から考えを広げます。九マスの比較表とは用途が異なります。 |
| マインドマップ | 心智圖 | mind map | 中心の話題、枝、二次的な考えを示します。 |
| 概念マップ | 概念圖 | concept map | 複数の概念と関係を示します。線だけで因果は証明できません。 |
| 比較行列 | 比較矩陣 | comparison matrix | 二組の観点が交わるマスを使い、条件と単位を定めます。 |
| 特性要因図／魚骨図 | 魚骨圖 | fishbone diagram | 結果、主な原因群、下位の要因を未確認の仮説として示します。 |
| 絵コンテ | 故事板 | storyboard | 連続した場面、出来事、カットの下書きです。 |

これは目録内の用語統一で、出典や商標の結論ではありません。
