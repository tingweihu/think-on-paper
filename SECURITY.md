# Security

Do not put credentials, private notes, identifying data, or sensitive file paths in issues, examples, or generated outputs.

The local generator rejects linked paths and writes outside its checkout. This guard is not an operating-system isolation guarantee; run untrusted changes in an appropriately isolated environment.

For ordinary bugs, use the repository's issue tracker when available. Do not post sensitive vulnerability details publicly. A private reporting channel has not yet been configured, so no private contact address or response time is claimed here.
