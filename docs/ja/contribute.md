# 協力する

[ホーム](../../README.ja.md) · [繁體中文](../zh-TW/contribute.md) · [English](../en/contribute.md)

新しい形式を提案する前に [`catalog-144.csv`](../../catalog-144.csv)、三言語の一覧、既存形式のManifestを確認します。区画の構造や書き方が既存形式とどう違うか説明してください。線間、向き、紙色だけの変更は既存形式の変種です。構図の関数、安定したID、三言語の用途と制約、実行できる手順、同じ図形を使う記入例を追加し、生成とQAを実行します。空白版には文字、ページ番号、日付、ロゴを入れません。

翻訳を直す場合は制約、例、印刷上の注意を残し、人による確認の有無を明示します。未確認のデジタルプレビューを校正済みとは表現しません。印刷の不具合は倍率、用紙、測定結果を伝え、私的なメモは含めないでください。本プロジェクト独自のコード、文書、例、図は [MIT](../../LICENSE) です。

コード、文章、図の投稿ごとに作者と出典を記し、MITで提供する権利があることを確認してください。第三者の画像、フォント、商標、他人のノートを直接追加しないでください。外部からの投稿には出典と権利の確認が必要です。
