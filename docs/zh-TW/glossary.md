# 三語術語表｜繁體中文基準

[返回首頁](../../README.md) · [English](../en/glossary.md) · [日本語](../ja/glossary.md)

| 繁體中文 | English | 日本語 | 本專案用法 |
|---|---|---|---|
| 康乃爾式筆記頁 | Cornell notes | コーネル式ノート | 本專案的可列印版型；提示欄、主筆記、摘要三區。「康乃爾筆記法」可指使用方法；不宣稱特定研究效果。 |
| 曼陀羅思考／九宮展開 | mandala idea expansion | マンダラ式の発想／九マス展開 | 中心主題向周邊展開；九宮比較矩陣另有不同用途。 |
| 心智圖 | mind map | マインドマップ | 中央主題與分支、次級概念。 |
| 概念圖 | concept map | 概念マップ | 多概念及其關係；連線不自動代表因果。 |
| 比較矩陣 | comparison matrix | 比較行列 | 兩組維度的交叉格；標明條件與單位。 |
| 魚骨圖 | fishbone diagram | 特性要因図／魚骨図 | 問題、主因與支因；圖線表示待查假設。 |
| 故事板 | storyboard | 絵コンテ | 連續場景、事件或鏡頭草圖。 |

譯名用於本專案導覽與文件，並非對方法來源或商標權利的結論。
