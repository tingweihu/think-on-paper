# 印刷と用紙

[ホーム](../../README.ja.md) · [繁體中文](../zh-TW/print.md) · [English](../en/print.md)

各フォーマットには、左上に英語名を記した `titled.pdf` もあります。書き込み用の図形は文字のない `blank.pdf` と同じです。PNG は引き続き文字のない PDF から作ったプレビューです。

印刷には各フォーマットの `blank.pdf` を使い、PNG は閲覧用としてください。暫定ページはA5（148 × 210 mm）です。プリンターでA5を選び、「実際のサイズ」または100%から試してください。「ページに合わせる」を重ねると罫線間隔が変わる場合があります。まず一枚印刷し、書ける領域を測ってから調整します。

PDFに全面の淡い黄色は印刷されません。色付きの用紙では用紙自体が色を担い、暖色のデジタル画像は閲覧時の見本です。左側に綴じ余白、上下に各12 mmの安全余白を設けています。プリンター固有の印刷不可領域で欠ける可能性があるため、最初の紙面を確認してください。

各形式には同じ図形と余白の濃い線のSVG/PDF（`a5-contrast`）もあります。線をはっきりさせたいときは、例えば[濃い線の4象限PDF](../../templates/quadrant/exports/a5-contrast/blank.pdf)を選べます。
